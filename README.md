# LookChat

تطبيق متعدد المنصات للدردشة واكتشاف الأشخاص القريبين بموافقتهم. المشروع مبني باستخدام Expo SDK 58 وReact Native، ويستخدم Supabase للمصادقة والبيانات.

## نسخة الويب التجريبية

- يتم نشر نسخة الويب من فرع `feature/web-preview` عبر GitHub Actions إلى GitHub Pages.
- بعد تفعيل Pages مرة واحدة من إعدادات المستودع واختيار **GitHub Actions** كمصدر للنشر، يكون رابط المعاينة: `https://ahmedgamal9333.github.io/Look-chat/`.
- افتح الرابط عبر HTTPS واسمح للموقع بالوصول إلى الموقع الجغرافي عند تفعيل الظهور أو البحث عن القريبين.
- تسجيل الدخول والبريد التأكيدي والموقع والدردشة تحتاج اختبارًا يدويًا بعد أول نشر.



## إعداد التشغيل

1. انسخ `.env.example` إلى `.env`.
2. ضع مفتاح Supabase Publishable/anon في `EXPO_PUBLIC_SUPABASE_ANON_KEY` (لا تستخدم service_role مطلقًا).
3. نفّذ `npm install` ثم `npx expo install --fix`.
4. نفّذ `npx expo start`.

## بناء APK

عند رفع التغييرات إلى `main`، يبدأ GitHub Actions ببناء APK تجريبي، ويمكن تنزيله من صفحة Actions بعد نجاح التشغيل.

## الخصوصية

الموقع اختياري، ولا يعرض التطبيق إحداثيات المستخدمين لبعضهم. يعرض فقط المسافة التقريبية للمستخدمين الذين فعّلوا الظهور.

> لا تضع أي مفاتيح سرية أو ملف `.env` في المستودع العام.
